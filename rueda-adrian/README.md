OVA-TGS


¿De qué trata este repositorio?

Este repositorio contiene los archivos necesarios para ejecutar y visualizar un sitio web educativo dedicado a la Teoría General de Sistemas (TGS).

La página fue construida como un recurso de aprendizaje digital que integra explicaciones, representaciones de sistemas y situaciones prácticas para relacionar la teoría con el campo de la ingeniería.

¿Qué encontrarás en la página?

El sitio está organizado mediante un recorrido de aprendizaje:

1. Exploración conceptual: presentación de la TGS, sus antecedentes y conceptos principales.
2. Comprensión de los sistemas: características, clasificación y principios.
3. Representación: explicación del funcionamiento de los sistemas a través de sus componentes y relaciones.
4. Contexto tecnológico: ejemplos de la TGS en los sistemas de información y la ingeniería de sistemas.
5. Aplicación: análisis de un caso práctico.
6. Refuerzo del aprendizaje: juegos, ejercicios, material audiovisual y evaluación.

Funcionalidades principales

- Navegación entre los diferentes apartados del contenido.
- Explicaciones dinámicas de los componentes de un sistema.
- Juegos con comprobación inmediata de respuestas.
- Ejercicios con mensajes de retroalimentación.
- Material audiovisual integrado en la página.
- Cuestionario final con cálculo automático de resultados.
- Diseño adaptable a diferentes tamaños de pantalla.

Organización de los archivos

El proyecto utiliza una estructura sencilla para separar el contenido, la presentación visual y el comportamiento de la página.

Archivo o carpeta| Función
"index.html"| Contiene la estructura y los apartados del OVA.
"css/estilos.css"| Define la apariencia visual y la adaptación de la página.
"js/app.js"| Controla las interacciones y actividades.
"img/"| Almacena los recursos gráficos.
"videos/"| Carpeta destinada a los recursos audiovisuales locales.
"README.md"| Documentación del repositorio.

¿Cómo ejecutar el proyecto?

No requiere instalación de dependencias ni configuración de un servidor backend.

Opción 1: desde Visual Studio Code

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Localiza "index.html".
4. Inicia Live Server.
5. El sitio se abrirá en el navegador predeterminado.

Opción 2: directamente desde el navegador

Abre el archivo "index.html" en un navegador actualizado. Para una experiencia de desarrollo y prueba más cómoda, se recomienda Live Server.
