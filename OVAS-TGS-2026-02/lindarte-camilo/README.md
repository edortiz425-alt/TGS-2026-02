# OVA · El enfoque sistémico

Proyecto final de **Teoría General de Sistemas** (Ingeniería de Sistemas, Universidad Simón Bolívar, 2026-2).

- **Tema asignado:** N.º 12, El enfoque sistémico
- **Autor:** William Camilo Lindarte Villamizar
- **Enlace publicado:** https://lindarte-r7.github.io/

## Qué incluye
Contextualización, explicación conceptual con referencias, ejemplos, ejercicios con retroalimentación, 2 juegos interactivos, videos, quiz con puntaje automático, navegación responsive y página de créditos.

## Tecnologías
HTML, CSS y JavaScript (un solo archivo `index.html`, sin dependencias).

## Inteligencia Artificial
Claude (Anthropic) como apoyo para generar y ajustar el código y redactar contenidos, con revisión del autor.

## Cómo verlo
Publicado en la web, o abrir `index.html`. Para que los videos de YouTube se vean, abrirlo desde un servidor (GitHub Pages, Netlify, Vercel o Live Server).
