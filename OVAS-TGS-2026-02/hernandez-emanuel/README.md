# Conexiones – OVA de Teoría General de Sistemas

## Descripción
Conexiones es un Objeto Virtual de Aprendizaje (OVA) desarrollado para la asignatura de Teoría General de Sistemas. Busca facilitar la comprensión de sus conceptos fundamentales mediante contenidos educativos y actividades interactivas.

## Objetivo
Ofrecer un recurso educativo digital que permita comprender los fundamentos de la Teoría General de Sistemas de manera dinámica e interactiva.

## Contenido
- Introducción a la Teoría General de Sistemas.
- Conceptos fundamentales.
- Ejemplos y casos prácticos.
- Actividades interactivas.
- Recursos audiovisuales.
- Evaluación de conocimientos.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- GitHub Pages
